# Image Processing Toolkit

A Python-based image processing application that performs a variety of operations on images including filtering, face detection, resizing, and cropping using OpenCV.

## Features

- **Resize** — Change image dimensions
- **Crop** — Extract specific regions from an image
- **Grayscale** — Convert image to black & white
- **Blur** — Apply Gaussian blur
- **Edge Detection** — Canny edge detection
- **Sepia Filter** — Vintage warm tone effect
- **Invert Filter** — Negative of the image
- **Multiple Filters** — Chain filters together in one go
- **Face Detection** — Detects faces using Haar Cascade classifier

## Technologies Used

- Python
- OpenCV (cv2)
- NumPy

## How to Run

1. Install dependencies:
pip install opencv-python numpy
2. Run the script:
python IMAGE_PROCESSING.py
3. Enter the path to your image
4. Choose an operation from the menu
5. Optionally save the processed result

## Concepts Applied

- Digital Image Processing
- Spatial Filtering
- Edge Detection (Canny Algorithm)
- Haar Cascade Face Detection
- Matrix Transformations (Sepia kernel)
